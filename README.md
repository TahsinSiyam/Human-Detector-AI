# Human-Detector-AI
This is a simple Human Detector AI made by PyTorch. It takes a photo as Input and says is it human or non-Human.It needs datasets to run in the datasets there is two subfolder human and non-human that contains a lot of images and it matches the input with them and output.
#How to Run it
1. pip install pytorch
2. python main.py
3. make sure you have datasets folder in same folder.
4. to input a file copy and rename "test.png"
